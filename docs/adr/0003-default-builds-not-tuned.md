# Both shells are built with their scaffolded defaults, unsigned, secure defaults on

Each candidate is built exactly as its own tooling scaffolds it: `cargo tauri build` with the template's release profile and default capability file and CSP, and electron-builder as generated with the sandbox and context isolation on. Nothing is tuned for size or speed on either side, and neither installer is signed. The author's geobench report shipped a size-tuned Tauri release profile, which made the size row a comparison of one tuned build against one default build; this page instead shows what a team gets on day one, and records every relevant flag in the run's protocol block so a reader can see what was and was not set. Tuning both sides equally was rejected because there is no agreed definition of equal tuning across a Rust binary and a Chromium bundle.
